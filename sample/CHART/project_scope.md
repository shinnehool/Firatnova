# 项目定位

## 目标
- 以 PixelDiT / Diffno论文思路为基础，重写并适配医学图像 4× 超分。
- 面向单通道灰度医学图像，重点是可训练、可验证、可断点续训、可通过 yaml 统一调参。
- 当前硬件目标是 5060Ti 16GB，优先保证能稳定训练与诊断。

## 当前实现边界
- 已有独立训练脚本、推理脚本、smoke 脚本。
- 已有断点续训、验证指标、三联图、误差图、频谱图、逐样本报表。
- 核心算法不是原始扩散采样，而是 residual refinement 式重建模型。

## 数据约定
- `t2extrct` 是训练集。
- `test` 是验证 / 推理集。
- 输入为 LR，上采样到 HR 尺寸后送入模型；输出为预测残差，再与 LR_up 相加得到 SR。
